# Bundled data

- `players-2026.json`: normalized real player pool plus source/retrieval metadata, imported by the application at build time.
- `players-2026-audit.json`: provider identity matches, original ESPN totals, scoring notes, omissions and source hashes; maintainer audit trail, not imported by the UI.
- `players-template.csv`: one example row demonstrating the import contract, not enough players for a draft.
- `scoring-example.json`: two synthetic player rows illustrating stat-based receiver and fractional-kicker projections; not a complete player pool.

The synthetic practice pool is generated by `src/lib/sample.ts` and downloadable from setup. Do not confuse its plausible names with real forecasts. Full field definitions live in the [import contract](../README.md#importing-real-2026-data), with adapter details in [data provenance](../docs/DATA.md).

Regenerate real data with `npm run refresh:data`; do not hand-edit provider totals without documenting a source and updating the audit. Current source coverage and timestamps live inside the JSON metadata, which is authoritative if narrative examples become older. A new app release does not automatically mean a new player snapshot.
